# MemeFace

Ты корчишь рожу — программа показывает вояка с такой же рожей.

Работает через вебку (у меня это телефон), в реальном времени, без интернета.
Пока умеет отличать спокойное лицо от улыбки. Остальное в процессе.

---

## Чтобы завелось

Нужен Python 3.11 или 3.12. Не самый свежий — под него библиотеки ещё не подвезли.

```
python -m venv venv
venv\Scripts\activate
pip install -r requirements.txt
python app.py
```

**Две вещи, без которых не запустится:**

1. **Модель.** Файл `models/face_landmarker.task` в репозиторий не входит, он весит
   почти 4 мегабайта. Качать [отсюда](https://storage.googleapis.com/mediapipe-models/face_landmarker/face_landmarker/float16/1/face_landmarker.task),
   класть в папку `models`. Искала я его непозволительно долго, так что вот прямая ссылка.

2. **Камера.** Если это телефон через iVCam — клиент на компе должен быть **запущен**.
   Закрыла окошко — камера исчезла из системы, программа ругается и выходит.

## Кнопки

| жмёшь | получаешь |
|---|---|
| `n` | «вот так выглядит моё спокойное лицо». Нажать один раз в начале |
| `p` | вывалить в консоль все 52 числа про твою мимику |
| `q` | всё, хватит |

**Про `n` — это не опция, это обязательно.**

У каждого лица свой фон. У меня, например, модель считает, что я постоянно слегка
вытягиваю губы трубочкой — просто такая форма рта. Если не вычесть этот фон,
программа будет уверена, что я всё время чему-то удивляюсь.

Так что: садишься, делаешь нормальное лицо, жмёшь `n`. Теперь программа знает,
от чего отсчитывать.

## Куда что кладётся

```
memes/

  gesture_point/ gesture_fist/ hands_on_face/  — ждут, пока я прикручу руки
  unused/                                — свалка
```

**Папка = состояние.** Захотела добавить мем — кинула картинку в нужную папку, всё.
В код лезть не надо, он сам подхватит.

## Как оно вообще понимает, что я улыбаюсь

1. OpenCV дёргает кадр с камеры.
2. MediaPipe скармливает кадр модели и возвращает **52 числа ПОСХАЛКО** от 0 до 1.
   Каждое — про одну мышцу: насколько растянут левый уголок рта, насколько
   опущены брови, насколько открыта челюсть. Называются блендшейпы.
3. Дальше я просто смотрю на нужные числа. `mouthSmileLeft` вырос с 0.00002 до 0.85 —
   значит улыбка.
4. Из папки этого состояния берётся случайный вояак.
